# Sable Markdown Writer roadmap

First priority: a dependable Markdown editor that keeps writers focused on one page, with safe saves, accessible shortcuts, calm themes, and ordinary files users control.

## Phase 0: Trustworthy (done in 0.10.0)

- Docs that match what's actually shipped.
- Long-document performance (large manuscripts, large writing folders).
- A beta update channel, separate from the stable Sparkle feed.
- Data safety: safer saves, and clearer recovery when something goes wrong.

## Phase 2: Story tools

- Card links between manuscript text and character/location/world-note cards.
- Corkboard and scene status.
- A relationships view.
- Manuscript insights.
- An in-story timeline.
- Margin comments.
- Print-ready PDF.
- Footnotes: insert and renumber while writing, show in Reading Mode, and export as real footnotes.
- Page view: see writing as printed pages, add page breaks, and optionally show a page count.
- Export presets, including MLA and APA student papers.

## Phase 3: Beyond one Mac

- iPad and iPhone.
- Localization.
- Shareable themes.
- Shortcuts and Spotlight integration.
- Optional Mac App Store distribution.

## Phase 4: Exploring

- A study-focused version of Sable for coursework (academic export, sources, and assignment notes), sharing Sable's code. Not decided yet.

## Not planned

- Generative AI.
- Accounts or a cloud service.
- Real-time collaboration.
- Streaks.
