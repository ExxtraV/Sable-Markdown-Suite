Sable Markdown Writer 1.0.0-beta.1 is the first beta on the way to 1.0. It lets you open any Markdown file without setting up a writing folder, lays out your exports the way you choose, and adds an optional writing goal with a deadline. Betas go only to people who turned on **Get beta updates** in Settings → General; everyone else stays on 0.10.1 until a stable release.

- **Open any Markdown file, with or without a writing folder.** A writing folder is now optional. First launch offers **Just Open a File** beside choosing a folder, and a file opened from Finder skips setup altogether. With no writing folder, the writing desk shows the open file's own folder. If you do have a writing folder and open a file from somewhere else, the desk stays on your folder and adds one quiet line with **Show Folder**, which shows the file's folder for now, with a **Back to** link. Your saved writing folder never changes. Saving, the Trash notice with **Put Back**, and snapshots all work on the open file wherever it lives. Settings → General → **Writing folder** chooses a folder later or stops using one; Sable only forgets the folder, and no file is touched.
- **Make Sable your default for Markdown, only if you choose.** Settings → General → **Markdown files** shows which app opens Markdown now and has **Make Sable the Default for Markdown**; macOS asks you to confirm. Plain text (`.txt`) has its own button. Sable never changes either by itself.
- **A Recent tab, if you want one.** Turn on **Recent tab** in Settings → General → Writing desk and the desk gains a **Recent** tab listing the files you've had open, newest first, from any folder. It's off by default, records only while it's on, and stays on your Mac. Turning it off forgets the list, and **Clear Recent Files** empties it any time.
- **More Markdown file types.** `.mdown`, `.mkd`, `.mkdn`, and `.mdwn` now count as Markdown in the writing desk, search, import, and the Open panel. File → Open Markdown File… adds to Open Recent, and dropping a Markdown or text file on the page opens it.
- **Choose how an export is laid out.** The Export sheet has a new **Layout** section. Headings can sit on the left or centered, the title page can be on or off and left or centered, and you pick the font, the size, single, 1.5, or double line spacing, the margins, and whether pages show numbers and a running header. The Manuscript and Book looks are still there as starting points; picking one fills in its usual layout, and **Reset** goes back to it. PDF and Word follow every choice, and EPUB follows the heading and title page alignment. Each Fiction Project remembers its own layout, and File → Export This Document… remembers one for single documents, which can now have a title page too.
- **Two changes to the Book look.** It now uses Palatino in both the PDF and the Word file (the PDF used Charter before, which most Windows computers don't have), and single line spacing with 1-inch margins, so a Book PDF is a little tighter than before.
- **A goal with a deadline, only if you want one.** For a challenge like 50,000 words in November, turn on **Track a goal with a deadline** in Settings → General, then pick the **November: 50,000 words** preset or **Custom…** with your own word count and dates. Settings shows your words so far, where an even pace would have you today, what today needs for the goal to finish on time, and the days left, charted against a dashed pace line. If you're under pace, Sable says so in plain numbers ("1,900 a day finishes on time"). There are no streaks, badges, or notifications, and like the writing record it counts only words you add. A small "1,204 / 1,667 today" can sit beside the session goal in the footer if you turn on **Show today's share in the footer**. With the switch off, nothing about goals appears anywhere, and a goal you set earlier is kept. **Clear Goal** keeps your writing record, and clearing the record keeps your goal. Both stay on this Mac.
- **A sample project to explore.** First launch now offers **Explore a Sample Project** beside choosing a folder, and **Help → Open Sample Project** opens it any time. It's *Northwatch*, a short finished story in a real Fiction Project: three chapters with scene tags, four character cards (one with aliases and a portrait), two locations, a world note, a Concept note, an Outline tagged for the Story Timeline, a note to yourself, and a snapshot to compare against. Sable copies it into your Documents folder as **Sable Sample Project** (a number is added if that name is taken) and opens the first chapter. It doesn't set your writing folder, and the copy inside the app is never edited. Opening it again brings back your copy as you left it; move it to the Trash first to start fresh.

**Fixed**

- With a Fiction Project showing in the writing desk and a file from somewhere else open, Revision History and Save Snapshot used the project's chapters. The file you have open now decides what a snapshot covers, and name highlights follow the open file too.
- A long title on the PDF title page ran off the page. It now wraps within the margins.
- Dropping a Markdown or text file on the page pasted its path into your text. It now opens the file.
- File → Open Markdown File… didn't add the file to Open Recent. It does now.
